# 剪辑判断

工具保证「切得准」，这份文档讲「剪得好」：留哪一遍、删什么、多长、哪里加图形。规则都来自真实成片和创作者本人的修改意见。

## 一、先通读，再动手

1. 把 `analysis/phrases.tsv` 从头读到尾，用一句话写下这条视频讲什么。
2. 看完 `analysis/sheets/` 里每一张联系表，列出「画面事故」的原片时间段：
   - 镜头晃到天花板、掉在桌上、人低头只露头顶、人出画
   - 举东西给镜头看（演示画面，**要保留**，但要用原画机位）
   - 照片 / 截图素材对应她在说哪一句
3. 定结构，常见的三种：
   - **要点型**：钩子（结果或反常画面）→ 我凭什么讲（资历一句话）→ 「分成 N 个方面」→ 逐条 → 一句祝福 → 招牌结束语
   - **故事型**：钩子（最强情绪的一句）→ 起因 → 转折 → 感受 → 对观众说的话 → 结束语
   - **见闻型**：现场一句 → 看到了什么（照片）→ 为什么值得 → 号召 → 结束语
4. 开场第一句必须是钩子。原片开头如果是「大家好今天我想说一下」，就把后面最有冲击力的一句（或照片）提到最前面。

## 二、一句话说了好几遍：留哪一遍

- 留**最后说顺的那一遍**。前面的半句、「不对不对」「我重新说」全删。
- 两遍都完整时，留语气更自然、更有笑容的那遍（看联系表上的表情）。
- 说错又在下一句纠正的（「第一个说眼镜……第一个说口罩」），只留纠正后的。
- 前后说法矛盾时（「里面是棉的」→ 后面又说「里面也是丝的，中间是一层棉的」），只留最后的说法，不要两个都留让观众困惑。
- whisper 会把连着说的重复合成一句（「要命了要命了我一边是高兴」被算进上一句的结尾），下一句再出现时就重复了两遍。**每版都要看质检的回听转写，同一个词出现两次就是这个问题**，用 `skip` 挖掉重复的那几百毫秒。

## 三、删什么

按优先级：

1. 镜头事故（天花板、人出画、扶手机）——**哪怕只有两三秒，创作者一定会看出来**。
2. 口误、重说、半句、语气词堆叠（「然后呢」「就是」「好」）。
3. 回指和预告（「上一次我有说过」「等一下我会讲」）。
4. 枝节解释（「因为它怕重量太重」），删了不影响理解就删。
5. 同一个意思说了两次的，留更具体的那次。
6. 听不清的方言、俗语：**不要猜字幕**。删掉或只留后半句，交付时告诉用户「这里听不清，原话是什么告诉我可以加回去」。

不删：

- 她自己笑场、对着镜头的小互动（「请你们不要笑得太厉害」之后自己先笑）——这是人味，留 1～2 秒。
- 演示动作（拿出东西、戴上、展示正反面），即使没说话也留一点。

## 四、长度和节奏

- 7 分钟原片 → 2 分 30 秒左右；3 分钟原片 → 1 分 40 秒左右。第一版超过目标 20% 就再删一轮枝节，不要靠加速。
- 1.3 倍速是老年创作者的默认（她们说得慢）；本来语速快的人 1.15～1.2。
- 段落之间 `gap_after` 0.5～0.65，给观众换气；同一段内 0.3～0.4。
- 列举（「第一个…第二个…」）每条后面停顿稍长，配合目录卡。

## 五、机位

- 默认让程序在原画 / 推近之间交替（每个机位至少 2.8 秒）。
- 举东西、戴口罩演示、手势大的句子：`"frame": "wide"`，不然推近会切掉东西。
- 全片最有冲击力的 2～4 句：`"frame": "emph"`（特写），比如「简直是吓死人了」「或者有人偷偷放屁」。
- 片尾签名期间（`pages`）固定原画。

## 六、字幕怎么断

- 一屏 ≤ 11 个汉字，按语义断，不按字数硬切：「我不要叫空中服务人员|给我水」。
- 关键词用【】标琥珀色，每屏最多一个，全片 20～30 个。
- 字幕写**她实际说的话**（去掉口误后的），不改写、不书面化；同音错字要改（「瞎昏」→「吓昏」）。
- 被图形代替的句子标 `nocap`，并在 `caption_hide` 里让开，避免字幕和大字叠在一起。
- 读速超过 7 字/秒的提示可以接受少量（短句），太多说明断得太碎。

## 七、图形放哪

- 第一秒：钩子图形（照片墙 / 题字），第 0 帧就要有东西。
- 「分成 N 个方面」：目录卡，随她说出逐格出现；最后一格（悬念）用深色。
- 分段讲：每段开头挂章节签，一直挂到这段结束。
- 数字、百分比、口号：金句大字，数字用 Instrument Serif 斜体 + 金色。
- 说到某个人 / 某张照片：人物出场或照片墙；后面再提到同一张照片时回扣一次。
- 其余时间让人脸说话，不要加。

## 八、常见修改意见和改法

| 意见 | 原因 | 改法 |
|---|---|---|
| 「X 秒到 Y 秒我人不在里面」 | 镜头事故没删干净 | `frames` 确认原片范围，在对应句加 `skip`；没说话的话就整段删 |
| 「这句讲了太多次」「重复了好几遍」 | whisper 把重复合进相邻句 | `listen` 找每一遍的边界，`skip` 掉多的；改回普通字幕 |
| 「人头太大、有压迫感」 | 手机前置摄像头离脸近 | 开抠像 `matte`，`scale` 0.70；背景换她指定的颜色 |
| 「背景是白的、衣服也是白的」 | 白墙白衣糊成一片 | 抠像换浅色纯色底（浅紫、浅蓝），纸面 `vars.paper` 同步换 |
| 「字幕挡住了」 | 平台 UI / 计时器 | 字幕区固定在 1262～1394px，不要往上或往下挪 |
| 「把我换成某人的照片」 | 说到别人时想让观众看到那个人 | `guest` 人物出场，照片放 `stills/` |
| 「需要加快速度」 | 停顿或枝节多 | 先删枝节、压 `gap_after`，最后才考虑提 `speed` |
| 「片尾要用某首歌」 | 招牌 | 见 `声音.md` 片尾歌接唱 |

改完只动被指出的地方，重新跑质检，草稿名递增。
