# 声音

## 人声

`prepare` 对原片声音做一条固定的处理链，剪辑和成片都用处理后的人声（`analysis/voice_clean.wav`）：

1. 两级 85Hz 高通：去空调、桌面震动的低频轰鸣
2. `afftdn` 轻降噪（nr=10）：手机自拍的底噪，再强会有水声
3. 均衡：220Hz -1.5dB 去闷，3.2kHz +2.5dB 提清晰度，9kHz 高架 +1.5dB 加空气感
4. `deesser` 去齿音
5. 2.5:1 轻压缩 + 3dB 补偿

拼接时每个切点两侧各 12ms 等功率淡入淡出（不会咔哒），最后整体 `atempo` 变速（不变调）。

有声 / 无声的判断阈值是 -41dBFS（20ms 窗、10ms 步进），短于 0.12 秒的缝合并。切点都贴在这些边界上，所以不会切掉半个字。

## 背景音乐

默认用 Kevin MacLeod 的《Wholesome》（CC BY 4.0，`setup.sh` 从 incompetech 下载；**发布时要在简介或片尾署名**：`Wholesome – Kevin MacLeod (incompetech.com), CC BY 4.0`）。轻快、不抢人声、适合生活分享。

- 电平 -31.2dB，从第 1.244 秒开始（跳过前奏的空拍）
- `duck`：她说话时保持 -31.2，停顿时抬高 5dB，包络起 60ms、落 450ms，句间不会忽高忽低
- 人声结束前约 7 秒淡出，把位置让给片尾歌

换别的曲子：放进 `sources/`，改 `file` 和 `offset`；电平先用 -31，听一遍再调。

## 片尾歌「接唱」

如果创作者有招牌结束语（比如每条都以「Don't worry, be happy」结尾），片尾用同名歌曲，让歌手**紧接着她的话唱出同一句**，是整条片子最有记忆点的一秒。做法是三段：

```json
{"file": "sources/end_song.m4a", "offset": "26.90-8.46", "start": "END_SPEECH-9.0", "end": "END_SPEECH-0.54",
 "level": -37.0, "duck": true, "lift": 6, "fade_in": 1.6, "fade_out": 0.45},
{"file": "sources/end_song.m4a", "offset": 34.85, "start": "END_SPEECH+0.35", "end": "TOTAL",
 "level": -15.7, "fade_in": 0.05, "fade_out": 2.4}
```

1. **前奏垫底**：人声结束前 9 秒起，用歌曲前奏（口哨段）在 -37dB 垫在她的结束语下面，前奏的结尾对齐到她说完前 0.54 秒。`offset` 写成「前奏结束时间 − 垫底时长」，这样不管片子多长，前奏总是刚好在她说完时走完。
2. **接唱**：她说完 0.35 秒后，从歌手唱出这句歌词的那一刻（上例是第 34.85 秒）正常音量切入，一直放到片尾，最后 2.4 秒淡出。

换歌时只需要找两个时间点：前奏结束的秒数、歌手唱出那句的秒数。

**版权**：流行歌曲不随技能分发，用户自己提供音频文件，并自行确认平台的音乐版权规则（视频号、抖音一般可以用平台曲库里的同一首歌）。

## 响度

混音后做两遍 `loudnorm`：目标 -15 LUFS、真峰值 -1.5 dBTP（短视频平台的常见目标，手机外放够响又不爆）。质检会再测一遍。
