# 剪辑表 `edl.json` 字段

一条视频一个工程目录，目录里一个 `edl.json`。`new_project` 会写好默认值，你主要填 `items`、`overlays`、`caption_hide`。完整的真实例子：`examples/edl.example.json`。

三套时间（脚本里随处可见）：

- **原片时间**：`analysis/source.mkv` 里的秒数。`phrases.tsv`、`skip`、`cap_src`、`listen`、`frames` 都用它。
- **剪辑时间**：按剪辑表拼起来、变速前的秒数（只在程序内部用）。
- **成片时间**：变速后的秒数 = 剪辑时间 ÷ speed。图形锚点、配乐、质检报告都用它。

## 顶层

| 字段 | 默认 | 说明 |
|---|---|---|
| `title` | `""` | 片名，只用于 HTML 标题和你自己辨认 |
| `language` | `"zh"` | whisper 转写语言 |
| `sources` | — | 口播视频（相对工程目录），按顺序拼接 |
| `asr_fixes` | `[]` | 同音错字校正 `[["王小美","王晓美"], …]`，**前后必须等长**；改完运行 `ths phrases $P` |
| `speed` | `1.3` | 整片变速（人声不变调）。老人、慢语速 1.3；本身语速快的人 1.15～1.2 |
| `fps` | `30` | 成片帧率 |
| `gap` | `0.38` | 切点处保留的停顿（成片里约 0.29 秒） |
| `max_pause` | `0.6` | 同一句里超过这么长的停顿也会被压到 `gap` |
| `min_shot` | `2.8` | 一个机位至少停多少秒（成片时间）才允许换 |
| `soft_frames` | `4` | 同机位接点的交叉淡化帧数 |
| `end_extra` | `6.8` | 人声结束后片尾再延长多少秒（片尾歌、定格） |
| `items` | — | 成片里的句子，按播放顺序，见下 |
| `pages` | `[]` | `[{"from_p":"P116","to_p":"P118"}]`：这几句固定原画、不换机位（片尾相框期间必须写） |
| `full_cover` | `[]` | `[{"o_in":秒,"o_out":秒}]`：全屏图形盖住人像的成片时间段，期间不换机位 |
| `overlays` | `[]` | 图形，见 `设计规范.md` |
| `caption_hide` | `[]` | `[["P11-0.1","P14.end+0.5"], …]`：这些时段不出普通字幕（被目录卡、金句、片尾代替） |
| `music` | 见下 | 配乐 |
| `matte` | 无 | 抠像换背景：`{"bg_pre":"#D2CCE6","scale":0.70}`，见 `设计规范.md` |
| `vars` | 无 | 覆盖设计变量，比如 `{"paper":"#E6DCEF"}`（抠像换浅紫后，纸面也要换成同色） |
| `source` `phrases` `faces` `voice` `frames` | analysis/… | 一般不写；想换素材位置时才用 |

## `items`：每一句

```json
{"p": "P62", "keep": "我全脸全身都是被包得紧紧的", "skip": [[219.0, 220.5]],
 "cap": "我全脸全身|都是被包得【紧紧的】", "frame": "emph", "gap_after": 0.6}
```

| 字段 | 说明 |
|---|---|
| `p` | 句子编号（`phrases.tsv` 第一列）。必填 |
| `keep` | 只用这句里的一部分，写出要保留的原文（必须是原句的连续子串）。从字缝里最安静的地方下刀 |
| `skip` | `[[起,止], …]`：从这句的原片范围里挖掉几段（原片秒）。用来去掉夹在中间的「不对」「分三个」、镜头事故、重复的半句。边界用 `ths listen` 定 |
| `cap` | 这句的字幕。`|` 分屏，`【】` 标关键词（琥珀色）。一屏 ≤ 11 个汉字。不写就按 11 字自动断 |
| `cap_span` | 这条字幕覆盖接下来几句（含自己），后面几句不写 `cap` |
| `cap_src` | 每一屏开口的原片秒数 `[6.91, 14.51]`。只在 whisper 逐字时间严重不准、字幕明显早晚时用 |
| `nocap` | `true`：不出字幕（被金句大字、目录卡代替，或开场钩子上已经有字） |
| `quote` | `true`：字幕用楷体，表示「别人说的话」 |
| `frame` | 从这句开始的机位：`wide` 原画、`tight` 推近 1.14、`emph` 特写 1.24。不写就按 `min_shot` 自动交替 |
| `gap_after` | 这句后面留多长停顿（默认 `gap`）。段落之间 0.5～0.65，句内紧凑处 0.3 |
| `gap_inner` | 句内长停顿压缩后保留多少 |
| `head` | 句首多留的起音（默认 0.09 秒） |
| `tail` | 只对最后一句有效：结束语后留多长尾音（默认 0.45，片尾常用 1.6） |
| `cut_after` | `true`：即使和下一句在原片里连着也强制切开 |

相邻两句如果在原片里本来就连着、中间停顿不长，程序不会切，原样保留，画面不跳。

## 锚点（图形、`caption_hide` 里的时间）

| 写法 | 意思 |
|---|---|
| `P41` / `P41.end` | 这句第一个字开口 / 最后一个字结束 |
| `P41@综合` / `P41@综合.end` | 这句里「综合」开口 / 「合」结束 |
| `P41@综合+0.2`、`P41-0.1` | 再加减秒数 |
| `END±秒` | 人像底片结束（成片时长）±秒 |
| `SE±秒` | 人声最后一个字结束 ±秒 |

改了剪辑表重新出片，所有锚点自动跟着走，不用手调时间。

## `music`

```json
"music": {"lufs": -15.0, "tp": -1.5, "voice_db": 0,
  "clips": [
    {"file": "$HOME/music/Wholesome.mp3", "offset": 1.244, "start": 0, "end": "END_SPEECH-7.2",
     "level": -31.2, "duck": true, "lift": 5, "fade_in": 0.8, "fade_out": 2.4,
     "auto": [{"from": 40, "to": 52, "db": -4, "ramp": 0.4}]}
  ],
  "sfx": [{"file": "sources/click.mp3", "t": 17.3, "db": -20}]}
```

| 字段 | 说明 |
|---|---|
| `file` | 相对工程目录；`$HOME/` 开头指 `~/.cache/talking-head-shorts/`。文件不存在会跳过并提示 |
| `offset` | 从音乐的第几秒开始用 |
| `start` / `end` | 成片里的起止。可以写表达式：`END_SPEECH`（人声结束）、`TOTAL`（总长），如 `"END_SPEECH-0.54"` |
| `level` | 电平（dB）。背景乐 -31 左右；片尾歌正常播放 -15.7 |
| `duck` / `lift` | 说话时保持 `level`，不说话时抬高 `lift` dB（平滑过渡） |
| `auto` | 某段时间再额外加减 dB |
| `sfx` | 音效：`t` 是成片秒数（或 END_SPEECH 表达式），`db` 电平 |
| `lufs` / `tp` | 整体响度和真峰值目标（两遍 loudnorm） |

片尾歌「接唱」的写法见 `声音.md`。
