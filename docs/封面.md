# 封面

视频号 / 小红书竖版封面：3:4，导出 1242×1656。风格和系列保持一致：浅色底、真人抠图在下半部分、上半部分超粗大标题、关键词金黄色。

## 步骤

1. **取人像帧**：在成片里找一帧表情最好、和主题有关的（拿着橘子大笑、戴着口罩比手势），从原片导出并套上同样的调色：

```bash
G="$(scripts/ths render_base --print-grade)"
ffmpeg -ss 367.0 -i $P/analysis/source.mkv -frames:v 1 -vf "hqdn3d=1.2:1.0:0:0,scale=1088:1920:flags=lanczos,$G" -q:v 1 $P/out/人像参考.jpg
```

2. **生图**：把人像参考图上传给能编辑图片的生图模型（Gemini「制作图片」、GPT-Image 等），宽高比选 3:4，用下面的提示词（改标题、关键词、人物描述）。**只上传这一期的人像**：同时上传上一期封面当风格参考，模型会把人换成上一期的样子。

```text
请生成一张图片：竖版 3:4 的短视频封面海报。把我上传照片里这位【手里捧着几个橘子、开心大笑的奶奶】完整抠出来（从头顶到胸口，连同她的手和手里的东西），放在画面下半部分，保持她的脸、发型发色、眼镜、笑容、衣服完全不变，真实照片质感，不要美颜、不要改变五官和年龄、不要卡通化。背景换成干净明亮的【暖米白色】，带一点柔和的光晕和人物投影。画面上半部分是超大标题，分两行：第一行「【71岁坐飞机】」，第二行「【这样保护自己】」。字体是超粗的黑体海报字，黑色字配很粗的白色描边、厚重的立体挤出和投影；「【71岁】」和「【保护】」改用饱和的金黄色（#FCD70C）并带粗黑描边和暖金外发光。标题约占画面上半部分 40%，上下各留约 7% 边距，文字不要遮住她的脸和头发。标题文字必须和给定的完全一致，一个字都不能错，不要出现任何其他文字、水印、图标、卡通吉祥物。
```

3. **核对**：逐字核对标题（生图模型常错字、多字）；人是不是这一期的样子（眼镜、发色、衣服）。不对就重新生成，不要手修文字。
4. **导出**：拿模型的**原尺寸**图（Gemini 网页下载的是 1792×2400 原图，预览图只有 768×1024），然后：

```bash
scripts/ths cover_export 原图.jpg $P/out/封面.jpg
```

## 换底色

视频抠像换了浅紫背景后，创作者可能要求封面也统一。不要重新生成（标题和人会变），在原图上只把米白底和头后的暖光晕换成目标色：见 `scripts/cover_recolor.py`。

```bash
scripts/ths cover_recolor 原图.jpg 换色后.png "#E6DCEF"
scripts/ths cover_export 换色后.png $P/out/封面.jpg
```
