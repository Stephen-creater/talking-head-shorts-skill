# 设计规范

一句话：**人物画面和图形印在同一张纸上**。墙调成纸色（或抠像换成纯色底），图形是纸面上的墨字和一笔暖金，动效像在纸上书写，不像屏幕特效。

## 颜色（`hf_build.py` 里的 `VARS`，可在 edl 的 `vars` 覆盖）

| 变量 | 色值 | 用途 |
|---|---|---|
| `paper` | `#EFEDE6` | 纸面底色（照片墙背景、片尾、画面缩小后露出的底） |
| `halo` | `#FBF8F2` | 字的描边（纸白） |
| `ink` / `ink2` / `ink3` | `#2A2230` / `#5E5662` / `#9A9298` | 正文墨色 / 次要 / 更弱 |
| `gold` / `gold2` | `#F2B33D` / `#E3A12F` | 全片唯一强调色：下划线、数字、章节号 |
| `amber` | `#B8690A` | 字幕里的关键词 |
| `line` | `#D8D2C6` | 卡片边框 |

画面调色（`render_base.py` 的 `GRADE`）：白墙校成暖白（约 RGB 239,237,230，和 `paper` 同色），肤色自然，饱和度只加 5%，CAS 锐化 0.45。原片分辨率低（如 544×960）时，推镜和放大到 1080×1920 合成一次 Lanczos 采样，不做 AI 超分（会把老人脸变塑料）。

## 字体（`setup.sh` 自动下载，全部开源）

| 家族 | 文件 | 用途 |
|---|---|---|
| Sans / SansB / SansM | 思源黑体 Noto Sans SC（可变字重 900/700/500）；本机有鸿蒙黑 HarmonyOS Sans SC 会优先用 | 字幕、信息 |
| Serif | 思源宋体 Noto Serif SC | 标题、金句、章节签、目录卡 |
| Kai | 霞鹜文楷 LXGW WenKai Medium | 别人说的话、片尾签名 |
| LatinI | Instrument Serif Italic | 数字、英文短语 |
| Script | Caveat | 片尾手写结束语 |
| Mono | DM Mono | 时间码 |

每次出片按实际用到的字裁成 woff2 子集，渲染快、不丢字。

## 版面

- 画布 1080×1920。
- **字幕区固定**：top 1262、高 132（画面 66%～73%）。往上会挡脸，往下会被平台的标题、按钮、进度条、以后素材里的计时器挡住。
- 字幕：黑体 900、74px、墨色字 + 14px 纸白描边（`paint-order: stroke fill`）+ 柔和投影；超过 880px 宽自动缩字，最小 60px。
- 图形的主区在 y 1100～1450（脸下方、字幕附近）；左上角 y 214 留给章节签；顶部 150～300 留给开场标题。
- 动效：只用 `power3.out` 缓出位移 + 淡入（0.3～0.6 秒）、画线、擦除。不弹跳、不闪、不旋转（照片墙的轻微倾斜除外）。

## 图形清单（`overlays`）

所有时间都是锚点（见 `剪辑表字段.md`）。下面的例子都来自真实成片。

### `title` 开场题字

第 0 帧就完整显示，压在人像下半部分；期间第一句一般 `nocap`。

```json
{"type": "title", "to": "P02-0.1", "kicker": "小美奶奶", "line1": "70岁学 AI", "line2": "学出[瘾]来了"}
```

`[ ]` 里的字下面画一笔金色下划线。可选 `y`（默认 1096）。

### `photos` 照片墙

整屏纸面，两张照片像拍立得一样斜放；可带标题。适合「看到我这几张照片……」开场，后面提到时再回扣一次。

```json
{"type": "photos", "from": "P01-0.05", "to": "P01.end+0.3", "srcs": ["photo1.jpg", "photo2.jpg"],
 "ats": ["P01-1", "P01@照"], "kicker": "小美奶奶 · 飞过六七十个国家", "head": "坐飞机，我这样<b>保护</b>自己"}
```

照片放 `stills/`。可选：`ats` 每张出现的时刻、`top`（默认 360）、`lefts`、`rots`（倾斜度）、`w`/`h`（410×820）、`pos`（裁切对齐，如 `"50% 100%"` 保留下半部分）、`hs`（标题字号 92）。字幕照常显示在照片下方。

### `toc` 目录卡

```json
{"type": "toc", "from": "P11-0.1", "to": "P14.end+0.5", "items": [
  {"text": "口罩", "at": "P11@口"}, {"text": "眼镜", "at": "P12@眼"},
  {"text": "卫生习惯", "at": "P13@卫"}, {"text": "秘密武器", "at": "P14@秘", "secret": true}]}
```

2×2 纸卡，随她说出逐格出现，`secret` 那格用深色（留悬念）。期间 `caption_hide` 同一段。

### `chip` 章节签

```json
{"type": "chip", "from": "P47-0.1", "to": "P62.end+0.4", "num": "2", "text": "眼镜"}
```

左上角墨色签「2/4 眼镜」，整段一直挂着。可选 `of`（总数，默认 4）、`y`。

### `golden` 金句大字

逐词随发音出现，代替字幕；适合数字和口号。

```json
{"type": "golden", "from": "P46-0.05", "to": "P46.end+0.5", "sub": "上厕所的时候", "words": [
  {"text": "绝对要", "at": "P46@绝"}, {"text": "100%", "at": "P46@100", "gold": true, "latin": true},
  {"text": "安全", "at": "P46@安全"}]}
```

`gold` 金色，`latin` 用 Instrument Serif 斜体（数字、英文）。可选 `y`（1200）、`size`（116）。对应句子标 `nocap`。

### `strip` 纸条（对比、计数）

```json
{"type": "strip", "from": "P03@我普通", "to": "P04.end+0.3", "label": "以前", "cells": 3, "cw": 120, "ch": 40,
 "heads": ["第1天", "第2天", "第3天"], "fills": [{"cell": 0, "at": "P03@三天"}, {"cell": 1, "at": "P03@三天+0.15"}]}
```

### `guest` 人物出场

说到某个人 / 某个地方时，整屏纸面 + 一张相框照片 + 墨色名牌，照片缓慢推近。

```json
{"type": "guest", "from": "P29-0.1", "to": "P31.end+0.2", "src": "teacher.jpg", "win": [140, 262, 800, 838], "tag": "王老师"}
```

`win` = [x, y, 宽, 高]。照片提前裁成 800×838 放 `stills/`。

### `pivot` 划掉 / `word` 西文大字

```json
{"type": "pivot", "from": "P20", "to": "P22.end", "small": "以前我以为", "big": "问问题？", "big_at": "P21", "strike_at": "P22"}
{"type": "word", "from": "P75@Hands", "to": "P75.end+0.4", "text": "Hands on"}
```

### `end` 片尾

画面缩进白相框，楷体签名逐字擦出，手写结束语分两段出现，金色弧线，最后一帧定格并极慢推近。

```json
{"type": "end", "from": "P116-0.05", "win": [132, 252, 816, 860, 0.755], "center": [540, 1000],
 "name": "小美奶奶", "name_at": "P116@小美", "name_end": "P116.end",
 "h1_at": "P118", "h2_at": "P118@be", "arc_at": "SE+3.1", "say1": "Don't worry,", "say2": "be happy"}
```

`center` 是人脸在满屏画面里的中心（抠像缩小后脸会下移，约 [540, 1000]）。同时在 `pages` 里把这几句固定原画，在 `caption_hide` 里写 `["P116", "END+10"]`。

## 抠像换背景

创作者觉得「人头太大有压迫感」，或者白墙白衣糊成一片时用。

```json
"matte": {"bg_pre": "#D2CCE6", "scale": 0.70},
"vars": {"paper": "#E6DCEF"}
```

- `scale`：人像缩小比例（0.70 ≈ 头小三成）。人贴画面底边、左右居中，两侧衣服淡出，不会有竖直切边。
- `bg_pre`：**调色前**的底色。画面还要过一遍调色（暖、提亮），所以要反推：想要成片里是 `#E6DCEF` 浅紫，`bg_pre` 填 `#D2CCE6`。换别的颜色时用下面命令试算，再把结果填进 `vars.paper`，纸面和背景就是同一种颜色：

```bash
G="$(scripts/ths render_base --print-grade)"; ffmpeg -v error -f lavfi -i "color=c=0xD2CCE6:s=64x64" -frames:v 1 -vf "$G,format=rgb24" -f rawvideo pipe:1 | od -An -tu1 -N3
```

- 抠像模型（RobustVideoMatting）会把举在手里的东西当背景抠掉；程序额外把「颜色鲜艳或很深」的区域算作前景（橘子、口罩、手都能保住），前提是原来的墙是浅色素墙。
- 抠像速度约每秒 27 帧（2 分半的成片约 5 分钟）；之后只改字幕、图形不会重抠。
