# 踩过的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 字幕比声音早或晚 0.3～1 秒 | whisper 整片的逐字时间不准，常把起点算进前面的停顿 | 程序已把起点挪到下一段有声开头、挤在一起的字均分；个别句子仍不准就用 `cap_src` 手写每屏开口时间 |
| 剪掉的句子里的碎词还在（「分三个」「多的」） | whisper 的句子边界和真实停顿不一致 | `ths listen` 看真实边界，`skip` 挖掉 |
| 同一句重复两遍 | 连着说的重复被 whisper 合进相邻句 | 同上；每版都查回听转写 |
| 片头第二句前有好几秒静音 | 句首停顿被算进 token | 程序按有声区间收掉两头静音；仍有就 `skip` |
| 同机位接点画面跳一下 | 两个切点用的是同一个机位 | `shots.py` 在同机位接点自动做 4 帧软切；不要给相邻句手动指定同一个 `frame` 又期望它换机位 |
| 抠像把手里的东西抠掉了 | 人像抠像模型只认人 | 已自动把鲜艳 / 深色区域算前景（要求浅色素墙）；彩色墙面不适用 |
| `--prompt` 不起作用 | whisper-cli 加了 `-mc 0` 后忽略提示词 | 整片转写不加提示；`listen` 逐段时可以加 |
| OpenCV 报没有 CascadeClassifier | OpenCV 5 删了旧人脸检测器 | `pip install 'opencv-python<5'`（setup 已固定） |
| ffmpeg 没有 drawtext / ass | Homebrew 某些版本不带 libfreetype / libass | 字幕和图形全部走 HyperFrames（HTML 渲染），不依赖这两个滤镜 |
| `npx hyperframes` 每次去联网检查新版本 | npx 行为 | setup 全局安装固定版本，脚本优先用全局的 |
| AI 超分后老人的脸像塑料 | 超分模型抹掉皱纹和皮肤纹理 | 不用超分；一次 Lanczos 放大 + CAS 锐化 |
| 渲染时电脑卡死 | 多路渲染（每路 3～4 个无头浏览器）+ whisper 同时跑 | 一次只跑一个 build；`THS_WORKERS` 控制 HyperFrames 并行数（默认 4） |
| 生图模型把人换成了上一期的样子 | 同时上传了上一期封面当风格参考 | 只传这一期的人像，风格用文字描述 |
| 生图下载到的是 768×1024 小图 | 拿的是网页预览图 | 用「下载原图」，Gemini 原图 1792×2400 |
| 删文件时删错了 | 用变量拼路径 `rm -rf $D/*` | 删除写完整绝对路径，或 `"${D:?}"/*` |
